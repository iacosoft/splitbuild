# splitbuild
split &amp; build tool 
SPLIT è un divisore di file in segmenti. Programma di indubbia utilità che ci consente di dividere file di grosse dimensioni in file più piccoli e trasportarli da un computer ad un altro mediante floppy. Una volta trasportati sull'hard disk dell'altro computer potranno essere riuniti in modo da ricreare il file originale.

Il programma funziona al prompt del Dos e pertanto è consigliabile a utenti esperti. È disponibile una breve guida on line per essere subito operativi.
